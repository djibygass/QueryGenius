# QueryGenius
## Overview
This project is a web application designed to convert natural language text into SQL queries using a fine-tuned OpenAI GPT model. It features a web-based interface for easy interaction, API connectivity for model access and cloud-based data storage.

## Features
- **Natural Language to SQL Translation**: Converts user-input text into SQL queries using AI.
- **API Integration**: Utilizes a fine-tuned OpenAI GPT model through an API.
- **Cloud Storage**: Stores session data and user queries securely in the cloud using AWS services.

## Prerequisites
- Python
- Flask for the web framework
- OpenAI API for accessing the GPT model
- AWS SDK (Boto3) for cloud interactions
